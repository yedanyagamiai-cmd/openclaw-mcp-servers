## Description

OpenClaw is a set of 9 free MCP servers with 49 AI tools, running on Cloudflare Workers worldwide.

**The problem:** AI assistants like Claude and Cursor need external tools (JSON formatting, regex building, color palettes, timestamps, etc.), but setting up MCP servers usually means installing packages, configuring Docker, and managing infrastructure.

**The solution:** Paste one URL into your AI tool's settings. No install. No account. No API key for the free tier. It just works.

**What's included (all free to start):**
- JSON Toolkit — format, validate, diff, query, transform, generate schema
- Regex Engine — build patterns from plain English, test, explain, replace
- Color Palette — generate palettes, WCAG contrast check, CSS gradients
- Timestamp Converter — Unix/ISO conversion, timezone math, cron parsing
- Prompt Enhancer — score and optimize your AI prompts
- Market Intelligence — AI tool market reports and trend data
- Fortune & Tarot — daily horoscopes and tarot readings
- Content Publisher — markdown to HTML, SEO, English-Japanese translation
- AI Tool Compare — side-by-side comparison of AI coding tools

**Technical highlights:**
- <100ms latency (Cloudflare edge, 300+ global locations)
- MCP spec compliant (Streamable HTTP transport)
- Full trilingual docs (English, 繁體中文, 日本語)
- MIT open source

**Pricing:**
- Free: 1,000 calls/month (no account needed)
- Pro: $29/mo for all 9 servers + 50,000 calls/month
